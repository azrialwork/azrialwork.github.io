Keahlian

Keahlian yang saya miliki merupakan hasil dari rangkaian pengalaman di atas, sehingga setiap keahlian saya saling mendukung dan berhubungan langsung dengan jabatan yang saya emban.

Hard Skill

  • Pelayanan Pelanggan dan Penjualan — saya terapkan sebagai Customer Service Staff dalam membantu dan melayani kebutuhan pelanggan.
  • Pengoperasian Kasir dan Sistem Point of Sale (POS) — saya terapkan sebagai Cashier dalam memproses pembayaran tunai dan non-tunai, menerbitkan struk, serta menyusun laporan dan rekonsiliasi kas harian.
  • Pengendalian Persediaan dan Stock Opname — saya terapkan sebagai Inventory Control Officer dalam menghitung stok fisik, mencocokkannya dengan catatan, dan menindaklanjuti selisih stok.
  • Pembelian dan Pengadaan Barang — saya terapkan sebagai Purchasing Officer dalam menyusun pesanan, berkoordinasi dengan supplier dan distributor, serta memverifikasi barang yang datang.
  • Microsoft Word dan Microsoft Excel — saya gunakan untuk mendukung seluruh administrasi pekerjaan saya, mulai dari pencatatan, pengolahan data stok dan penjualan, hingga penyusunan laporan pembelian.
  • Pengembangan Web Front End — saya peroleh dari pengalaman saya sebagai Freelance Web Developer, termasuk dalam membangun website yang responsif dan mudah digunakan.

Soft Skill

  • Komunikasi — saya gunakan untuk melayani pelanggan, berkoordinasi dengan supplier, dan memahami kebutuhan klien selama saya menjadi freelance.
  • Ketelitian dan Keakuratan — saya terapkan ketika saya menghitung uang kas, menghitung stok, dan memeriksa kesesuaian barang dengan faktur.
  • Integritas dan Tanggung Jawab — saya pegang ketika saya dipercaya mengelola uang, persediaan, dan pembelian.
  • Kerja Sama Tim — saya terapkan agar alur pelayanan, transaksi, persediaan, dan pembelian berjalan selaras.
  • Manajemen Waktu — saya terapkan untuk membagi perhatian antara melayani pelanggan, mengelola transaksi, dan menyelesaikan tugas persediaan serta pembelian.
  • Pemecahan Masalah — saya terapkan ketika menghadapi selisih stok, kekosongan produk, maupun kendala transaksi.
  • Adaptabilitas dan Kemauan Belajar — saya buktikan melalui perjalanan saya dari bidang teknologi menuju bidang pelayanan dan operasional apotek.
