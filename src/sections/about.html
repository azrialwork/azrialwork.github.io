Tentang Saya

Saya Muhammad Azrial, lahir di Serang pada 2 Maret 2002 dan besar dengan ketertarikan pada dunia teknologi. Ketertarikan itu membawa saya mengambil jurusan Rekayasa Perangkat Lunak di SMK Negeri 1 Cilegon, tempat saya pertama kali belajar bagaimana sebuah perangkat lunak dan website dibangun.

Dari bangku sekolah, saya mulai mencoba terjun langsung dengan menjadi web developer freelance. Selama beberapa tahun saya mengerjakan berbagai website untuk klien, dan dari situlah saya belajar banyak hal di luar teknis — memahami orang, berkomunikasi, dan menyelesaikan tanggung jawab sampai tuntas.

Saat ini saya bekerja di Apotek Hayy Farma. Dunia yang berbeda dari teknologi, tetapi justru di sini saya belajar melayani orang secara langsung setiap hari. Bagi saya, perjalanan dari dunia website ke dunia pelayanan bukanlah perubahan arah, melainkan kelanjutan — saya tetap senang membantu orang, hanya medianya yang berbeda.

Website ini adalah ruang pribadi saya di internet. Ke depannya, halaman ini akan saya kembangkan menjadi tempat saya berbagi cerita, catatan, dan hal-hal yang sedang saya pelajari.
