# Muhammad Azrial — Curriculum Vitae

Situs CV pribadi saya, dapat diakses di **https://azrialwork.github.io**

## Stack

Sengaja dibuat seringan mungkin:

- HTML, CSS, dan JavaScript vanilla — tanpa framework
- Tanpa proses build dan tanpa dependensi
- Foto profil: `assets/profile.jpg`

## Deployment

Setiap push ke branch `main` otomatis men-deploy situs ini ke GitHub Pages
melalui GitHub Actions (`.github/workflows/pages.yml`, menggunakan
`actions/deploy-pages`).

## Mengubah Isi

Edit langsung file berikut, lalu commit dan push:

- `index.html` — isi CV
- `styles.css` — tampilan
- `script.js` — interaksi kecil (menu & tahun)
